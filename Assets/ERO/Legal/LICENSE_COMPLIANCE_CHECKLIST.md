# ERO — License Compliance Checklist

For every third-party asset:
- [ ] exact source URL recorded
- [ ] creator/provider recorded
- [ ] license name/version recorded
- [ ] license copy archived when permitted
- [ ] commercial use verified
- [ ] modification rights verified
- [ ] redistribution restrictions verified
- [ ] attribution requirement recorded
- [ ] share-alike/copyleft implications checked
- [ ] asset hash/version recorded
- [ ] asset appears in release manifest
- [ ] no copyrighted game/server extraction

For every software dependency:
- [ ] package name/version
- [ ] package license
- [ ] Unity/package terms checked
- [ ] notices included where required
- [ ] source obligations satisfied

FINAL RELEASE GATE:
Nothing with unknown provenance ships.
