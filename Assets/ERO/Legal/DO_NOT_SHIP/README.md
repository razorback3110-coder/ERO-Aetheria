# DO NOT SHIP

This directory is intentionally reserved for assets that must not enter a
commercial release until their rights are verified.

Examples:
- ripped MMORPG assets
- private-server client assets
- unverified internet downloads
- unclear-license music
- unclear-license fonts
- copyrighted screenshots/art used only as references

The ERO Character Creation reference image is an ART-DIRECTION REFERENCE.
It is not automatically a licensed game asset. Keep it isolated from
commercial release assets unless its rights are confirmed.
