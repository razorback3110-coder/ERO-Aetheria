# Vertical Slice Acceptance

The slice is considered functionally complete when:
- project opens in Unity 6000.0.67f1 without compile errors
- player can enter Greenhaven
- player can move and use combat
- at least one enemy can be fought
- loot can be obtained and represented in inventory
- Rift dungeon presentation works
- Rift Guardian encounter presentation works
- player can return to the world
- no blocker errors remain in Unity Console

Archive checks alone do not count as Unity runtime validation.
