3. Zone transitions -> loading screen -> dungeon/raid/PvP/GvG entry
4. UI -> inventory/equipment/skills/quests/social/guild/map/shop
5. Visual pass -> materials, fog, lighting, VFX, UI polish
6. Content pass -> maps, mobs, bosses, NPCs, quests, rewards
7. Multiplayer validation -> host/client, party, guild, PvP/GvG
8. Persistence -> account/profile/character/inventory/progression
9. Release pass -> licenses, credits, settings, save migration, build testing

standalone build and multiplayer tests have passed on the user's machine.
