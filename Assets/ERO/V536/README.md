# ERO V536 — Visual Final Pass

This version replaces the flat V533/V535 presentation with one ERO runtime layer.

- Original procedural stylized-elven player characters (male/female, 8 classes, hair/eyes/skin/face variations).
- Character creator is visible on first V536 profile and can be reopened with C or the Character menu.
- Same character construction is used for creator preview and world character.
- Zone-at-a-time world presentation to avoid the previous "all zones on one flat plane" look.
- Distinct visual treatments for Greenhaven, Everwood, Elyndor, Frostfall, Sunscar, Sylvaris, Abyssia and the Rift zones.
- Original procedural monsters and class weapons.
- Unified dark fantasy / blue-black-gold UI.
- Custom ERO glow shader included.

No ripped game assets are included. External CC0 assets can be imported later where desired.
