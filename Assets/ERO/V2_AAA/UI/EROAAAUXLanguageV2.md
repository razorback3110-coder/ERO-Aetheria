# ERO UI/UX AAA target

Keep the approved master character-creation reference as the visual anchor:
dark blue/black surfaces, gold highlights, refined typography, large character
preview, clean class navigation and premium MMORPG composition.

All screens should share:
- consistent spacing/grid
- readable hierarchy
- controller navigation
- keyboard/mouse navigation
- scalable 16:9 and 16:10 layouts
- localization-safe text boxes
- no legacy Boss Room visual panels in the visible presentation layer

Core screens:
Startup → Main Menu → Character Creation → Character Select → HUD → Inventory →
Equipment → Skills → Map → Quest → Party → Guild → Social/Chat → Market → Craft →
Housing → Codex → Achievements → Rankings → PvP/GvG → Dungeon → Raid → MVP →
World Boss → Settings → Steam integration.
