# V2 → AAA production roadmap

1. Replace procedural player with production-quality licensed character.
2. Add full locomotion and combat animation set.
3. Build one hero environment: Shadowspire Keep.
4. Add one fully authored boss with 3+ phases.
5. Add production VFX and audio.
6. Connect real inventory/equipment/skills HUD.
7. Add one complete dungeon loop: entrance → trash packs → mechanics → boss → loot.
8. Capture a real Unity gameplay sequence.
9. Profile PC and Steam Deck.
10. Only then scale the art pipeline to the remaining zones.

The vertical slice is the quality gate: the remaining game should inherit the same
character, material, lighting, VFX, animation and UI standards.
