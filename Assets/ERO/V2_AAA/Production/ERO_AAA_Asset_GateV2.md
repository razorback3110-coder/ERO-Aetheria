# Production asset gate

Every production asset must have:
- source URL/provider
- exact asset/pack name
- license type
- license/version evidence
- permitted commercial use confirmed
- modification permission confirmed
- redistribution/embedding conditions reviewed
- attribution requirement recorded
- replacement/removal plan if terms change

Approved source families already documented in the project:
- Poly Haven — CC0
- Kenney — CC0/public domain
- Quaternius — use only the exact pack/version covered by its commercial license
- Unity Asset Store — package/provider terms must be checked individually
- Noto Sans CJK — OFL-1.1
- Roboto — Apache-2.0

Do not use ripped assets, extracted models, textures, animations, music or UI
from Ragnarok, private servers, mobile games or other proprietary games unless
you have an explicit license that permits the intended commercial use.
