# ERO V539 — Commercial Asset Manifest

ERO will only ship third-party assets whose licenses explicitly permit the intended distribution.
Private-server rips, extracted Ragnarok assets, proprietary client files, copyrighted music, maps, sprites,
models, textures or effects are **not** included.

## Approved CC0 sources researched for ERO

- Quaternius Universal Base Characters — CC0; Humanoid rigs, hairstyles, eye/skin customization.
- Quaternius Modular Character Outfits - Fantasy — CC0; 12 outfits / 62 modular parts, Humanoid retargeting.
- Quaternius Fantasy Props MegaKit — CC0; 200+ fantasy props.
- Kenney Fantasy UI Borders — CC0; 140 UI border/panel assets.
- Kenney Retro Fantasy Kit — CC0; fantasy town/building props.
- Kenney Cartography Pack — CC0; map/cartography UI assets.

## Integration rule

Assets are to be imported from their official download pages and kept with their original license files.
Do not redistribute a downloaded pack unless its license permits redistribution in the chosen release form.

## ERO art direction

Third-party assets are presentation ingredients only. ERO's final identity remains:
Dark Fantasy + Anime Realistic + Cinematic MMORPG, using the approved ERO Character Creation reference as the
master UI/art-direction reference.
