# ERO V540 — Final Scope / Commercial MMORPG Test Build

The project now exposes a single feature contract covering the complete intended MMORPG surface: character creation, 8 classes, class evolution, Awakening, open-world zones, NPC/quest loop, combat, loot, equipment, crafting, pets, mounts, housing, party, guild, social, mail, trade, marketplace, Cristaux ERO, codex, achievements, collections, events, season/battle-pass, rankings, dungeon, raid, MVP, world boss, PvP/ranked, GvG, settings and localization.

## Visual direction
The Character Creation master reference at `Assets/ERO/ArtDirection/ERO_CharacterCreation_MasterReference.png` remains the visual anchor. The target is dark fantasy + anime-realistic + cinematic, with coherent black/blue/gold UI, detailed characters, readable silhouettes, strong VFX and authored environments.

## Important legal rule
Do not ship ripped assets from Ragnarok Online, private servers, MMOs, or other commercial games. Private-server files may be used only as inspiration or where the owner explicitly grants the necessary rights. Use CC0 or commercially licensed assets for redistributed builds.

## Test target
A tester should be able to follow: Startup -> Main Menu -> Character Creation -> Greenhaven -> combat -> loot -> equip -> quest -> progression -> zone travel -> dungeon -> raid -> MVP/world boss -> PvP/ranked -> GvG -> guild/social -> economy -> collection -> settings/localization.

V540 adds the final feature catalog and optional F10 feature launcher without replacing the existing playable runtime. Unity Play Mode remains the authoritative integration test.
