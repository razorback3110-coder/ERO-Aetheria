# ERO V6 Acceleration

Unity provides Multiplayer Play Mode to simulate up to four players on one development
device, and Multiplayer Tools includes profiling/network simulation utilities.
The Dedicated Server package allows a project to switch between client/server roles.

Use these native tools before paying for infrastructure:
1. Multiplayer Play Mode for 2-4 local clients.
2. Dedicated Server build for the authoritative world process.
3. Network simulation/profiling.
4. Only after the local loop is stable, deploy a cloud server.

This is the fastest credible route to validating ERO's MMO loop.
