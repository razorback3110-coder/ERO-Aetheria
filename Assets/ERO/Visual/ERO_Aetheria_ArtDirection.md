# ERO-Aetheria — Visual Production Direction

## Objective
Build a visually coherent MMORPG vertical slice before expanding feature breadth.

## Visual pillars
- Dark fantasy with blue, black and gold identity.
- High-contrast readable silhouettes during combat.
- Dense but performant world dressing.
- Distinct class silhouettes and elemental VFX.
- Original assets only; no proprietary game assets.

## Production order
1. Hero presentation: body, armor, weapon, idle/walk/run/attack/readable silhouette.
2. Aetheria hub: central plaza, buildings, roads, props, foliage, lighting and atmosphere.
3. Open-world biome: terrain, forest, rocks, ruins, ambient creatures and points of interest.
4. Combat presentation: hit reactions, spell/projectile VFX, ground telegraphs, death effects.
5. Enemy family: common, elite and boss silhouettes with unique attack readability.
6. Dungeon presentation: modular rooms, traps, treasure, boss arena and lighting.
7. UI presentation: polished HUD, action bar, inventory, equipment, map and character panels.
8. Optimization pass: LOD, pooling, occlusion, streaming and GPU/CPU budgets.

## Asset policy
Every external asset must have a documented commercial-use license in `Assets/ERO/Legal/ERO_Asset_License_Registry.md`. If license provenance is uncertain, the asset is not approved.

## Definition of visual progress
A change counts as visual progress only when it creates or improves something the player can see in the running game: geometry, materials, lighting, VFX, animation, environment dressing, character presentation or UI.

## Current milestone
Create a convincing playable Aetheria showcase scene using procedural/Unity-authored geometry as a temporary foundation, while keeping the architecture ready for replacement by licensed production assets.
