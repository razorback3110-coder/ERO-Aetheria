# ERO V540 — Complete MMORPG Feature Integration

This version expands the client-side production contract so the final test can exercise the full ERO feature surface: character, classes/evolutions, open world, dungeons, raids, MVP, world boss, PvP/ranked, GvG, guild, party, social, inventory/equipment, crafting, marketplace, trade, mail, pets, mounts, housing, codex, achievements, events, seasons, battle pass, rankings, premium currency and settings.

## Commercial asset rule
Only assets with explicit redistribution/commercial permission should be shipped. Do not copy/rip assets from Ragnarok Online, private servers, or other commercial games. Those can be references for UX/gameplay patterns only.

Startup -> Main Menu -> Character Creation -> Greenhaven -> combat -> loot -> equipment -> quests -> progression -> zone travel -> dungeon -> raid -> MVP/world boss -> PvP/ranked -> GvG -> guild/social -> economy -> collection -> settings/localization.
