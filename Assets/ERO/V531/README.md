# ERO V531 — Full UI/UX and Playable Presentation Layer

This version replaces the previous V528 master presentation with one unified ERO presentation layer.
It provides Startup, Main Menu, Character Creation and a universal in-game HUD/window system for any gameplay scene.

Included interfaces: character, inventory, equipment, stats, skills, quests, social, party, guild, pets, mounts, housing, marketplace, ERO Crystals shop, map, PvP, GvG, raids, MVP, World Boss, rankings, events, seasons and settings.

The presentation is intentionally self-contained and does not require changing the Boss Room gameplay/network components.
