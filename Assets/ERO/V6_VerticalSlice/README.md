# ERO Vertical Slice V6

Implemented directly in the GitHub project.

- Native ERO main menu before character creation/gameplay.
- Create Character -> same saved character is instantiated in Greenhaven.
- Continue -> enters the existing playable world.
- Character creator remains native ERO UI with RenderTexture preview.
- F8 reopens character creator.
- HUD/gameplay are hidden while menu or creator is open.
- Existing Windows + Linux build workflows remain unchanged.

This is an engineering vertical slice, not a claim of final AAA art or production MMO backend. Unity runtime/build must be verified on the configured ERO-PC runner.
