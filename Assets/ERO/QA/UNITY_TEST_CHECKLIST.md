# ERO Unity Test Checklist — First Real Test

Editor: Unity 6000.0.67f1

1. Open project in a fresh copy.
2. Wait for package import and script compilation.
3. Confirm Console has no compilation errors.
4. Open ERO_Playable.
5. Press Play.
6. Startup/loading screen.
7. Character Creation:
   - male/female
   - class selection
   - appearance
   - name
   - 3D preview
8. Create character.
9. Enter Greenhaven.
10. WASD/camera.
11. Target and combat.
12. Skills.
13. Enemy death/loot.
14. Inventory/equipment.
15. Quest and XP.
16. Zone transition/loading.
17. Dungeon/Raid/MVP/World Boss entry.
18. PvP/Ranked/GvG UI.
19. Guild/social/chat/trade/mail.
20. Pets/mounts/housing.
21. Localization.
22. Settings/resolution/fullscreen.
23. Quit/relaunch/save persistence.

Record every Console error with:
- exact message
- stack trace
- scene
- action that caused it
- screenshot/video if possible.
