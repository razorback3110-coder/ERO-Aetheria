# ERO V1 — Vertical Slice / AAA Target
Unity target: 6000.0.67f1

This V1 is the first focused vertical-slice layer for Eternal Realms Online.
Goal: move the playable presentation toward the approved anime dark-fantasy MMORPG
reference: third-person gameplay, cinematic camera, dungeon encounter, boss arena,
party/HUD presentation and a coherent ERO art-direction layer.

INSTALL
1. Start from ERO_V543_STEAM_TEST_READY.
2. Copy this folder into Assets/ERO/.
3. Open the existing ERO_Playable scene.
4. Add EROV1VerticalSliceBootstrap to an empty GameObject named ERO_V1.
5. Enter Play Mode.

IMPORTANT
This is an engineering/visual-slice layer, not a claim that the project is already
a finished AAA commercial MMORPG. It uses the existing ERO runtime and provides a
clean path for replacing procedural placeholders with licensed production assets.
No ripped/private-server assets are included.
