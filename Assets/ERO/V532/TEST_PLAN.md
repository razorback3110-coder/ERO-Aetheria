# ERO V532 Test Plan

1. Open with Unity 6000.0.67f1.
2. Press Play with the first build scene `ERO_Playable`.
3. Verify the real ERO character model loads from Resources/EROCharacters.
4. WASD + right mouse: movement/camera.
5. Left click/E: combat; 1-4: skills.
6. M: nearest target. F1-F8: switch class/model.
7. Kill monsters, gain XP, level up, collect Rift Fragments.
8. TAB/MAP: cycle zones; locked zones require their level.
9. SAVE: local save through EROFullGame.
10. Send the first Console errors and a Play Mode screenshot; do not repair the project manually before reporting them.

Important: this is a real playable vertical slice and the integration target for the next correction pass. It is not claimed to be a finished commercial MMORPG.
