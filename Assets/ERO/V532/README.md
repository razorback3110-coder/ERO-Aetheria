# ERO V532 - Playable Runtime

This scene is a self-contained playable vertical slice intended for the first real Unity test.

Flow: launch `Assets/Scenes/ERO/ERO_Playable.unity` -> generated Aetheria world -> real ERO class model -> movement -> combat -> skills -> enemies -> XP/levels -> loot -> HUD -> zone travel.

Controls:
- WASD move
- Right mouse orbit camera
- Left mouse / E attack
- 1-4 skills
- M select nearest target
- TAB travel through unlocked zones
- SHIFT sprint

The runtime uses the existing ERO character OBJ assets when available. It does not depend on Boss Room UI.
